# 🎬 SMARTVIDEO - Adsterra ও ব্যক্তিগত বিজ্ঞাপন সংযোগ নির্দেশিকা

এই ওয়েবসাইটে খুব সহজেই আপনার **[beta.publishers.adsterra.com](https://beta.publishers.adsterra.com)** অ্যাকাউন্ট থেকে বিজ্ঞাপন ও ডিরেক্ট লিংক কানেক্ট করতে পারবেন।

---

## ⚡ Adsterra বিজ্ঞাপন কীভাবে কানেক্ট করবেন?

### ১. Adsterra Direct Link (স্মার্টলিঙ্ক):
1. **Adsterra Dashboard** এ যান ➔ **Direct Links** মেনু থেকে একটি Direct Link তৈরি করুন এবং কপি করুন।
2. **`admin.html`** ওপেন করুন অথবা **`config.js`** ফাইলটি ওপেন করুন।
3. **`adsterra.directLink`** ঘরে আপনার লিঙ্কটি পেস্ট করুন।
4. **ফলাফল:** ভিজিটর প্লেয়ার, ভিডিও স্ক্রিন, ডাউনলোড বাটন বা অন্য কোথাও ক্লিক করলেই সাথে সাথে এই লিঙ্কটি ব্যাকগ্রাউন্ডে ওপেন হবে।

### ২. Adsterra Popunder Script (পপ-আন্ডার):
1. **Adsterra Dashboard** ➔ **Websites** ➔ আপনার ওয়েবসাইটের অধীনে **Popunder** সিলেক্ট করে **Get Code** এ ক্লিক করে কোড কপি করুন।
2. **`admin.html`** এর **"Adsterra Popunder Script"** বক্সে পেস্ট করুন।
3. **ফলাফল:** ভিজিটর পেজে প্রবেশ করলেই পপ-আন্ডার অ্যাড স্বয়ংক্রিয়ভাবে কার্যকর হবে।

### ৩. Adsterra Social Bar (ইন-পেজ পুশ):
1. **Adsterra** থেকে **Social Bar** কোড কপি করুন।
2. **`admin.html`** এর **"Adsterra Social Bar Script"** বক্সে পেস্ট করুন।
3. **ফলাফল:** ভিজিটরের স্ক্রিনে আকর্ষণীয় নোটিফিকেশন বার শো করবে।

### ৪. Adsterra Native Banner (নেটিভ ব্যানার):
1. **Adsterra** থেকে **Native Banner** কোডটি কপি করুন।
2. **`admin.html`** এর **"Adsterra Native Banner Code"** বক্সে পেস্ট করুন।
3. **ফলাফল:** ভিডিও প্লেয়ারের ঠিক নিচে ৪টি বা ১টি নেটিভ ব্যানার শো করবে।

### ৫. Adsterra 728x90 Top & Bottom Banners:
- **`admin.html`** এর ব্যানার বক্সে Adsterra কোড পেস্ট করে দিলেই স্বয়ংক্রিয়ভাবে ভিডিওর উপরে ও নিচে ব্যানার লোড হবে।
