# 🎬 SMARTVIDEO - ভাইরাল ভিডিও ল্যান্ডিং পেজ (ব্যক্তিগত বিজ্ঞাপন সহ)

এই ওয়েবসাইটটি আপনার দেওয়া ফেসবুক রিলের ভিডিওর অনুরূপ হাই-কনভার্টিং ভাইরাল ভিডিও স্ট্রিমিং ল্যান্ডিং পেজের ডিজাইনে তৈরি করা হয়েছে। এখানে **Adsterra** বা **Hit4Hit** এর উপর নির্ভর না করে সম্পূর্ণ আপনার **নিজের ব্যক্তিগত বিজ্ঞাপন (Personal Ads, CPA Offers, Direct Links, Banners)** যুক্ত করার পূর্ণ নিয়ন্ত্রণ রাখা হয়েছে।

---

## 📁 ফাইল পরিচিতি

| ফাইল | বিবরণ |
| :--- | :--- |
| **`index.html`** | মূল হাই-স্পিড ভিডিও ল্যান্ডিং পেজ (ডার্ক থিম, ৪কে লাইভ ব্যাজ, প্লেয়ার ও বিজ্ঞাপন স্লট)। |
| **`config.js`** | আপনার ব্যক্তিগত অ্যাড লিঙ্ক, ব্যানার, ভিডিওর টাইটেল ও থাম্বনেইল কনফিগারেশন ফাইল। |
| **`admin.html`** | ভিজ্যুয়াল প্রো অ্যাডমিন প্যানেল (কোড এডিট না করেই ব্রাউজার থেকে অ্যাড ও সেটিংস পরিবর্তনের ড্যাশবোর্ড)। |
| **`style.css`** | প্রিমিয়াম নিয়ন-গ্লো স্টাইলিং ও মোবাইল-রেসপন্সিভ ডিজাইন। |
| **`script.js`** | ক্লিক-টু-প্লে অটোমেটিক অ্যাড ট্রিগার, বাফারিং অ্যানিমেশন এবং হিউম্যান ভেরিফিকেশন লকার সিস্টেম। |

## 🚀 কীভাবে নিজের কম্পিউটারে চালু করে দেখবেন?

1. ফোল্ডারে থাকা **`index.html`** ফাইলটিতে ডাবল ক্লিক করুন অথবা গুগল ক্রোম/এজ ব্রাউজারে ওপেন করুন।
2. পেজটি সাথে সাথে আল্ট্রা-ফাস্ট স্পিডে লোড হবে।
3. প্লেয়ারে ক্লিক করলে একটি নতুন ট্যাবে আপনার দেওয়া ব্যক্তিগত লিঙ্ক ওপেন হবে এবং স্ক্রিনে বাফারিং অ্যানিমেশন চলবে।

## 🎯 কীভাবে নিজের পার্সোনাল অ্যাড (Personal Ads) যুক্ত করবেন?

### পদ্ধতি ১: ভিজ্যুয়াল অ্যাডমিন প্যানেল দিয়ে (সবচেয়ে সহজ)
1. **`admin.html`** ফাইলটি ব্রাউজারে ওপেন করুন।
2. **"১. ডিরেক্ট পার্সোনাল অ্যাড"** ঘরে আপনার সিপিএ অফার, অ্যাফিলিয়েট লিঙ্ক বা ব্লগের লিঙ্ক বসিয়ে দিন।
3. **"২. ব্যানার বিজ্ঞাপন স্লট"** এ আপনার ব্যানার ছবি ও লিঙ্কের ইউআরএল দিন।
4. **"💾 সেটিংস সেভ করুন"** বাটনে ক্লিক করুন।
5. সাথে সাথে আপনার `index.html` পেজটিতে নতুন বিজ্ঞাপন কার্যকর হয়ে যাবে!

### পদ্ধতি ২: `config.js` ফাইল এডিট করে
`config.js` ফাইলটি যেকোনো টেক্সট এডিটর (যেমন Notepad বা VS Code) দিয়ে ওপেন করে নিচের অংশগুলো পরিবর্তন করুন:

```javascript
personalAds: {
    // ১. প্লেয়ারে ক্লিক করলে যে লিঙ্ক ওপেন হবে
    directAdUrl: "https://your-personal-cpa-link.com",
    clickMode: "always", // 'always' অথবা 'first-click'

    // ২. স্পন্সরড অফার লকার
    contentLocker: {
        enabled: true,
        sponsoredOfferUrl: "https://your-cpa-offer.com"
    },

    // ৩. টপ ও বটম ব্যানার
    topBanner: {
        enabled: true,
        imageUrl: "আপনার ব্যানার ছবির লিঙ্ক",
        targetUrl: "ব্যানারে ক্লিক করলে যে লিঙ্কে যাবে"
    }
}
```

## 💡 প্রধান সুবিধাসমূহ

1. **অ্যান্টি-অ্যাডব্লক ফ্রেন্ডলি (Anti-Adblock Friendly):** কোনো থার্ড পার্টি অ্যাড কোডের ওপর নির্ভরশীল নয় বিধায় ব্রাউজারের অ্যাডব্লকার এটি ব্লক করতে পারে না।
2. **হাই সিটিআর ক্লিক-টু-প্লে (Click-to-Play):** ভিজিটর ভিডিও চালু করতে প্লে বাটনে ক্লিক করলেই ব্যাকগ্রাউন্ডে আপনার পার্সোনাল অ্যাড লোড হয়।
3. **হিউম্যান ভেরিফিকেশন লকার (Human Verification Locker):** বট ট্রাফিক আটকানোর মতো দেখতে আকর্ষণীয় সিকিউরিটি বক্স, যেখানে ক্লিক করলেই অফার রিডাইরেক্ট হয়।
4. **ফ্রি হোস্টিং সাপোর্ট:** কোনো ব্যাকএন্ড বা ডাটাবেস লাগে না। এটি সরাসরি **GitHub Pages**, **Netlify**, **Vercel** বা যেকোনো সাধারণ cPanel ডোমেইনে ফ্রি হোস্ট করা যায়।
